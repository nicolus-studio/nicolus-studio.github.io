# Site de Nicolus Studio

Site vitrine du studio, publié gratuitement avec GitHub Pages. Il sert à :
- valider le site web de l'organisation dans la Google Play Console (via Google Search Console) ;
- héberger la politique de confidentialité de chaque jeu (lien demandé par Google Play et AdMob) ;
- afficher les mentions légales (obligatoires en France pour un site professionnel) ;
- plus tard, héberger le fichier `app-ads.txt` d'AdMob, à la racine du site.

## Pages

| Fichier | Contenu |
|---|---|
| `index.html` | Accueil : le studio, les jeux, le contact |
| `mentions-legales.html` | Mentions légales |
| `primate-rush/confidentialite.html` | Politique de confidentialité de Primate Rush (FR) |
| `primate-rush/privacy.html` | Politique de confidentialité de Primate Rush (EN) |
| `style.css` | Mise en forme commune |

Pour un nouveau jeu : un dossier à son nom, avec sa propre politique de confidentialité, et une carte de plus sur l'accueil.

## Informations à compléter

Une information qui manque encore se surligne en jaune avec `<mark class="todo">`.
Avant chaque mise en ligne, il ne doit rester aucun `class="todo"` dans les fichiers.

Le site n'utilise aucun cookie, aucune mesure d'audience, aucune police ni aucun script externe : pas de bandeau cookies nécessaire.
